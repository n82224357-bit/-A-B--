Разработка A/B-тестирования и анализ результатов

Проект, выполненный с помощью Python. Данные, использованные в проекте, предоставлены сервисом Яндекс.Практикум.

Цель: проведести A/B-тестирование 

В результате, были выполнены следующие шаги:

- Проведена предобработка данных.
- Рассчитаны параметры теста.
- Оценена корректность проведения теста.
- Проанализированы результаты эксперимента.
